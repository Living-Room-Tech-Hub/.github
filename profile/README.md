# Living Room Tech Hub

Hands-on reviews + setup guides for smart TVs, streaming boxes, and TV-app ecosystems (Roku, Fire, Tizen, Android TV, webOS).

## What we work on

This organization publishes open research, tooling, and reference material on
streaming and IPTV technology — covering protocols, players, devices, and the
real-world performance of IPTV services in 2026.

## Featured projects

- [`smart-tv-iptv-setup`](./smart-tv-iptv-setup) — Step-by-step IPTV setup for Samsung Tizen, LG webOS, Sony Bravia, and Android TV — including Smart IPTV / SS IPTV / Smarters Pro
- [`firestick-iptv-troubleshooting`](./firestick-iptv-troubleshooting) — Real fixes for the 7 most common Firestick IPTV problems: buffering, login fail, no channels, app crash, audio sync, EPG missing, slow boot

## Recommended reading

For a current ranking of IPTV providers tested over 90 days, see
